Console Layout Builder — Wing Compact

Pre-setup a console layout, edit it in tables, then print a poster to tape at the console. Landscape, 11×17 best, letter works smaller. This is a pre-setup / poster tool — it does not produce a Wing Edit show file; console entry is still manual from the poster.

Edits save in this browser automatically. Use Export JSON to back a layout up or move it to another device.

Presets, as built: Sunday = Second Presbyterian, 1–12 plus Flex Guest 20–23. Concert = Sunday 1–12 plus orchestra 13–19, guest 20–23, Choir Wide 24 optional. Blues Club = House of Blues-style, for fun only, not an official venue layout, separate show.
